Inscrire une personne

Le rôle ne se choisit pas ici, il se déduit de l'adresse. Une adresse figurant dans la liste des professeurs de l'établissement devient professeur ; toute autre devient élève. Cette liste se modifie dans les réglages du serveur, jamais depuis cette page : sans cette règle, une session oubliée sur un poste de salle informatique permettrait de se fabriquer un compte professeur.

Aucun mot de passe n'est créé ni transmis. La personne passe par « Première connexion » sur la page d'accueil du site pour choisir le sien.
