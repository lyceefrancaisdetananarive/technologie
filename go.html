Ouvrir une ressource par son code

Saisis le code inscrit sous le QR code, par exemple 51A.

Le code se lit ainsi : le premier chiffre est le niveau, le deuxième le numéro de séquence, la lettre le type de document : A activité, S structuration, E évaluation, Q quiz, B version adaptée, R révision. 5D désigne l'évaluation diagnostique de 5ème.
