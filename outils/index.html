🎬 Ouvrir le dossier

🖨 Impression par lot

Assembler en un seul tirage tous les documents d'une séquence, d'une période ou d'un niveau, plutôt que d'imprimer page par page. Trois raccourcis sont prévus : les évaluations diagnostiques, le jeu complet d'une séquence, et tout ce que l'élève doit avoir pour la période en cours.

🖨 Ouvrir l'outil

🔗 Un lien et un QR code par activité

Chaque activité, évaluation, quiz, fiche de structuration, de révision et version adaptée du site possède un code court et un QR code. Un élève scanne, ou saisit le code à la main s'il n'a pas de lecteur.

Les codes se lisent ainsi : le niveau, le numéro de séquence, puis la lettre du document : A activité, S structuration, E évaluation, Q quiz, B version adaptée, R révision. Ainsi 43A est l'activité de la séquence 3 de 4ème.

📘 Guide de mise en place

🖨 Impression et export PDF

Chaque fiche d'activité et évaluation dispose d'un bouton "Imprimer / PDF" qui ouvre le dialogue d'impression de votre navigateur. Pour imprimer plusieurs documents d'un coup, une séquence entière ou le jeu complet d'une période, passez par l'outil d'impression par lot.

🖨 Assembler un lot
Conseils pour un bon rendu PDF
  • Utilisez Chrome ou Edge pour le meilleur rendu
  • Dans les options d'impression, choisissez "Enregistrer au format PDF" comme destination
  • Le format est optimisé pour du A4
  • L'en-tête LFT et les numéros de page apparaissent automatiquement
  • Les éléments de navigation sont masqués à l'impression
